# SENEMOS Nabu mainline kernel

This COPR source publishes the stable Linux 7.2.y Nabu kernel as
`senemos-nabu-kernel-mainline` with a conventional Fedora release number. The source
contains its own frozen checksum-locked device patch series, distinct ABI and
SENEMOS7 maintenance family. Development-channel updates therefore cannot
silently alter a stable-mainline rebuild.
